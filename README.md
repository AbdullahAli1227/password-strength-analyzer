# 🔐 Password Strength Analyzer
Professional Streamlit dashboard that scores passwords using entropy and pattern analysis, estimates crack time for online/offline attacks, checks known breaches (Have I Been Pwned, k-anonymity) and generates secure passwords and passphrases.

## Features
Entropy scoring | Pattern detection (keyboard walks, years, sequences, repeats) | Crack-time estimates | Breach lookup | Password and passphrase generator

## Run
    pip install -r requirements.txt
    streamlit run app.py

Deploy free on Streamlit Community Cloud to get a live demo link for your portfolio.
